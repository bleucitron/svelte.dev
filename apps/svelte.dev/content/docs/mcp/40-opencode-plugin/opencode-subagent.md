Le plugin Svelte inclut un sous-agent spécialisé appelé `svelte-file-editor` conçu pour créer,
modifier et passer en revue les fichiers Svelte.

## Avantages

Le sous-agent a accès à sa propre fenêtre de contexte, lui permettant de récupérer la documentation,
d'itérer avec l'outil `svelte-autofixer` et d'écrire dans le système de fichiers sans polluer le
contexte dans l'agent principal.

La délégation devrait se produire automatiquement lorsque pertinent, mais vous pouvez aussi demander
explicitement que le sous-agent soit utilisé pour des tâches liées à Svelte.
