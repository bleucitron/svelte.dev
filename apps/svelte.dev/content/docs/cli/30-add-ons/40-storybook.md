[Storybook](https://storybook.js.org/) est un atelier front-end pour vous aider à construire vos
composants.

## Usage

```bash
npx sv add storybook
```

## Ce que vous obtenez

- `npx storybook init` lancé pour vous depuis la même commande CLI `sv` utilisée pour tous les
autres add-ons
- [Storybook pour SvelteKit](https://storybook.js.org/docs/get-started/frameworks/sveltekit) ou
[Storybook pour Svelte & Vite](https://storybook.js.org/docs/get-started/frameworks/svelte-vite)
