[Better Auth](https://www.better-auth.com/) est une librairie d'authentification pour TypeScript
compatible avec n'importe quele framework.

## Usage

```sh
npx sv add better-auth
```

## Ce que vous obtenez

- une mise en place complète pour SvelteKit avec Drizzle comme adaptateur de base de données
- authentification via e-mail/mot de passe activée par défaut
- des pages de démo d'inscription et de connexion optionnelles

## Options

### demo

Quelles pages de démo inclure. Valeurs disponibles : `password` (e-mail & mot de passe), `github`
(GitHub OAuth).

```sh
# E-mail & Mot de passe uniquement (par défaut)
npx sv add better-auth="demo:password"

# GitHub OAuth uniquement
npx sv add better-auth="demo:github"

# À la fois E-mail & Password et GitHub OAuth
npx sv add better-auth="demo:password,github"
```
