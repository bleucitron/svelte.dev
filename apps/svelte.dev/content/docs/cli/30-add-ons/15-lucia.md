Une mise en place d'authentification basée sur le [guide d'authentification de
Lucia](https://lucia-auth.com/).

## Usage

```bash
npx sv add lucia
```

## Ce que vous obtenez

- une mise en place d'authentification pour SvelteKit et Drizzle suivant les bonnes pratiques venant
	du guide d'authentification de Lucia
- des pages optionnelles de démo pour l'inscription et la connexion

## Options

Si oui ou non inclure les pages de démo pour l'inscription et la connexion.

```bash
npx sv add --lucia=demo
```
