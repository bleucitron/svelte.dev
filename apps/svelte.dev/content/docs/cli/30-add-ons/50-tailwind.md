[Tailwind CSS](https://tailwindcss.com/) vous permet de construire rapidement des sites web modernes
sans jamais quitter votre HTML.

## Usage

```sh
npx sv add tailwindcss
```

## Ce que vous obtenez

- la mise en place de Tailwind suivant le [guide de Tailwind pour SvelteKit](https://tailwindcss.com/docs/installation/framework-guides/sveltekit)
- le plugin Vite pour Tailwind
- des fichiers `layout.css` et `+layout.svelte` (pour SvelteKit) ou `app.css` et `App.svelte` (pour
les applications Vite n'utilisant pas SvelteKit)
- une intégration avec `prettier` si vous utilisez ce paquet

## Options

### plugins

Quel plugin utiliser :

- `typography` — [`@tailwindcss/typography`](https://github.com/tailwindlabs/tailwindcss-typography)
- `forms` — [`@tailwindcss/forms`](https://github.com/tailwindlabs/tailwindcss-forms)

```sh
npx sv add tailwindcss="plugins:typography"
```
