[`@sveltejs/enhanced-img`](https://svelte.dev/docs/kit/images) sert des formats de fichier plus
petits comme `avif` ou `webp`, génère les tailles adéquates pour différents appareils, et définit
`width` et `height` pour éviter des décalages de layout (_layout shift_).

## Usage

```sh
npx sv add enhanced-img
```

## Ce que vous obtenez [!VO]What you get

- le plugin Vite `enhancedImages`
- la ré-écriture des balises `<img>` en `<enhanced:img>`
- `sharp` ajouté au builds autorisés lorsque vous utilisez pnpm
