[mdsvex](https://mdsvex.pngwn.io) transforme les fichiers markdown en composants Svelte — en gros
c'est MDX pour Svelte. Cela permet d'utiliser des composants Svelte dans votre markdown, ou du
markdown dans vos composants Svelte.

## Usage

```sh
npx sv add mdsvex
```


Vous pouvez optionnellement sélectionner les plugins officiels de mdsvex que vous souhaitez
installer à l'aide d'un prompt de recherche :

```sh
npx sv add 'mdsvex=plugins:callouts,toc'
```

Ce prompt interactif pré-sélectionne les données de page, les ancres, les tables des matières, les
graphiques, les blocs de code et les liens externes.

## Ce que vous obtenez

- mdsvex installé et configuré en tant que plugin Vite
- les fichiers `.svx` activés en tant que composants Svelte
- les [plugins officiels](https://mdsvex.pngwn.at/docs/plugins) sélectionnés installés et activés
- l'extension VS Code de mdsvex ajoutée à vos recommandations de workspace
- le plugin Prettier pour mdsvex installé et configuré lorque Prettier est présent
