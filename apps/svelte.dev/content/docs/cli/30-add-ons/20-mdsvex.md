[mdsvex](https://mdsvex.pngwn.io) est un préprocesseur markdown pour les composants Svelte — en gros
MDX pour Svelte. Cela permet d'utiliser des composants Svelte dans votre markdown, ou du markdown
dans vos composants Svelte.

## Usage

```bash
npx sv add mdsvex
```

## Ce que vous obtenez

- mdsvex installé et configuré dans votre fichier `svelte.config.js`
