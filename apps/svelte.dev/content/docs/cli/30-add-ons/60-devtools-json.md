`devtools-json` est un plugin Vite
[vite-plugin-devtools-json](https://github.com/ChromeDevTools/vite-plugin-devtools-json/) permettant
de générer à la volée sur le serveur de développement un fichier de paramètres de projet pour les
devtools de Chrome.

Il va empêcher ce log de serveur :

```sh
Not found: /.well-known/appspecific/com.chrome.devtools.json
```

## Usage

```bash
npx sv add devtools-json
```

## Ce que vous obtenez [!VO]What you get

- le plugin `vite` ajouté à vos options de plugins Vite.
