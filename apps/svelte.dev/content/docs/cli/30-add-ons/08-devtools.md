Les [DevTools de Vite](https://devtools.vite.dev) fournissent un dock de développement intégré dans
la page. L'add-on installe également les [DevTools de
Svelte](https://github.com/sveltejs/vite-devtools-svelte), qui ajoutent à ce dock les
fonctionnalités de Svelte de composant, de réactivité, de routing, et d'analyse de performance.

## Usage

```sh
npx sv add devtools
```

## Ce que vous obtenez [!VO]What you get

- `@vitejs/devtools`, `@sveltejs/vite-devtools-svelte`, et les outils d'inspection sélectionnés
installés en tant que dépendances de développement
- les deux plugins ajoutés à votre configuration Vite dans l'ordre nécessaire
- les panneaux d'inspection de Svelte dans le dock des DevTools de Vite
- un accès direct aux panneaux de Svelte à l'adresse `/.svelte-devtools/`
- un endpoint MCP pour les diagnostics Svelte lors du développement

## Options

### plugins

Quels plugins de DevTools Vite installer :

- `vitest`
- `rolldown`
- `vite`
- `oxc`

Vitest, Rolldown, et Vite sont sélectionnés par défaut.

```sh
npx sv add devtools="plugins:vitest,oxc,rolldown,vite"
```
