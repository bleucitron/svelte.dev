Les [outils Svelte dédiés à l'IA](/docs/ai/overview) peuvent aider votre LLM à écrire du meilleur
code Svelte.

## Usage

```sh
npx sv add ai-tools
```

## Ce que vous obtenez [!VO]What you get

Vous pouvez ajouter l'outil soit au travers du plugin Svelte officiel, ou en tant qu'outil
individuel.

- Le plugin Svelte contient l'ensemble des outils IA de Svelte (serveur MCP,
[skills](/docs/ai/skills), et sous-agents) et se maintient à jour tout seul. Il est disponible pour
Claude Code et OpenCode. Pour Claude Code, il s'active via l'ajout d'un fichier
`.claude/settings.json` — la première fois que vous ouvrez le projet, on vous demandera d'accepter
de faire confiance au workspace, puis le plugin sera automatiquement installé (aucun `/plugin
install` n'est nécessaire)
- Les outils individuels, pour les clients n'ayant pas de plugin (ou lorsque vous souhaitez choisir
exactement ce que vous installez) :
  - Une configuration MCP pour une installation [locale](/docs/ai/local-setup) ou
  [distante](/docs/ai/remote-setup)
  - Un [fichier README pour les agents](https://agents.md/) pour vous aider à utiliser le serveur
  MCP efficacement
  - Des [skills](/docs/ai/skills) pour les clients qui les supportent
  - Des sous-agents pour les clients qui les supportent

## Options

### ide

Le ou les clients que vous souhaitez utiliser, comme `'claude-code'`, `'cursor'`, `'gemini'`,
`'opencode'`, `'vscode'`, `'other'`.

```sh
npx sv add ai-tools="ide:cursor,vscode"
```

### delivery

La manière d'ajouter l'outil : `'plugin'` (le plugin Svelte, recommandé) ou `'tools'` (les outils
individuels).
Seulement demandé lorsqu'un client sélectionné supporte le plugin.

```sh
npx sv add ai-tools="ide:claude-code+delivery:plugin"
```

### tools

Quels outils individuels ajouter lorsque vous n'utilisez pas le plugin, comme `'mcp'`,
`'svelte-code-writer'`, `'svelte-core-bestpractices'`, `'svelte-file-editor'`.

```sh
npx sv add ai-tools="ide:cursor+delivery:tools+tools:mcp,svelte-file-editor"
```

### mcpSetup

L'installation MCP que vous souhaitez utiliser (`'local'` ou `'remote'`).
Uniquement pertinent lorsque vous ajoutez le serveur MCP en tant qu'outil individuel.

```sh
npx sv add ai-tools="mcpSetup:local"
```
