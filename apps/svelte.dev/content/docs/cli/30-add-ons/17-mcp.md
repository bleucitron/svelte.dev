[Le MCP de Svelte](/docs/mcp/overview) peut aider votre LLM à écrire du meilleur code Svelte.

## Usage

```sh
npx sv add mcp
```

## Ce que vous obtenez [!VO]What you get

- Une configuration de MCP correcte pour votre projet, selon votre votre IDE.

## Options

### ide

L'IDE que vous voulez utiliser comme `'claude-code'`, `'cursor'`, `'gemini'`, `'opencode'`,
`'vscode'`, `'other'`.

```sh
npx sv add mcp="ide:cursor,vscode"
```

### setup

L'installation que vous souhaitez utiliser.

```sh
npx sv add mcp="setup:local"
```
