L'add-on `devtools-json` installe
[`vite-plugin-devtools-json`](https://github.com/ChromeDevTools/vite-plugin-devtools-json/), qui est
un plugin Vite permettant de générer à la volée les paramètres de projet pour les DevTools de
Chromium sur votre serveur de développement. Le fichier est servi depuis
`/.well-known/appspecific/com.chrome.devtools.json` et informe les navigateurs Chromium de l'endroit
où se situe le code source de votre projet afin que vous puissiez utiliser la [fonctionnalité de
workspaces](https://developer.chrome.com/docs/devtools/workspaces) pour éditer les fichiers sources
dans le navigateur.

> [!NOTE]
> Installer le plugin va activer la fonctionnalité pour tous les utilisateurs et utilisatrices se
> connectant au serveur de développement avec un navigateur Chromium, et permet au navigateur de
> lire et écrire tous les fichiers au sein du dossier. Si vous utilisez la fonctionnalité AI
> Assistance de Chrome, ceci peut égalament provoquer l'envoi de données à Google.

## Alternatives

Si vous préférez ne pas installer le plugin, mais souhaitez tout de même éviter de voir un message à
propose d'un fichier manquant, vous avez quelques options.

D'abord, vous pouvez évitez que la requête soit générée sur votre machine en désactivant la
fonctionnalité dans votre navigateur. Vous pouvez faire cela dans Chrome en allant sur
`chrome://flags` et en désactivant l'option "DevTools Project Settings". Il peut également être
intéressant de désactiver l'option "DevTools Automatic Workspace Folders", puisque celle-ci est
très liée.

Vous pouvez aussi empêcher le serveur web de générer un message à propos de la requête entrante pour
tous les développeurs et développeuses de votre application en gérant la requête vous-même. Par
exemple, vous pouvez créer un fichier appelé `.well-known/appspecific/com.chrome.devtools.json` avec
le contenu `"Vade retro, Chrome DevTools !"` ou ajouter de la logique pour répondre à la requête
dans votre hook [`handle`](https://svelte.dev/docs/kit/hooks#Server-hooks-handle) :

```js
/// file: src/hooks.server.js
import { dev } from '$app/environment';

export function handle({ event, resolve }) {
	if (dev && event.url.pathname === '/.well-known/appspecific/com.chrome.devtools.json') {
		return new Response(undefined, { status: 404 });
	}

	return resolve(event);
}
```
