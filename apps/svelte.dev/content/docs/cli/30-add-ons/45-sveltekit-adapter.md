[Les adaptateurs SvelteKit](/docs/kit/adapters) vous permettent de déployer votre site sur de
nombreuses plateformes. Cet add-on vous permet de configurer des adaptateurs officiels fournis par
SvelteKit, mais un certain nombre d'[adaptateurs gérés par la
communauté](https://www.sveltesociety.dev/packages?category=sveltekit-adapters) sont aussi
disponibles.

## Usage

```bash
npx sv add sveltekit-adapter
```

## Ce que vous obtenez

- l'adaptateur SvelteKit choisi, installé et configuré dans votre fichier `svelte.config.js`

## Options

### adapter

Quel adaptateur SvelteKit utiliser :

- `auto` — [`@sveltejs/adapter-auto`](/docs/kit/adapter-auto) choisit automatiquement pour vous
l'adaptateur approprié à utiliser, mais est moins configurable
- `node` — [`@sveltejs/adapter-node`](/docs/kit/adapter-node) génère un serveur Node autonome
- `static` — [`@sveltejs/adapter-static`](/docs/kit/adapter-static) vous permet d'utiliser SvelteKit
	comme générateur de site statique (SSG)
- `vercel` — [`@sveltejs/adapter-vercel`](/docs/kit/adapter-vercel) vous permet de déployer sur
Vercel
- `cloudflare` — [`@sveltejs/adapter-cloudflare`](/docs/kit/adapter-cloudflare) vous permet de
déployer sur Cloudflare
- `netlify` — [`@sveltejs/adapter-netlify`](/docs/kit/adapter-netlify) vous permet de déployer sur
Netlify

```bash
npx sv add --sveltekit-adapter=node
```
