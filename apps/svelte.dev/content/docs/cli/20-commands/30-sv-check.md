`sv check` exécute [`svelte-check`](https://npmx.dev/package/svelte-check) dans votre projet et
reporte les erreurs et avertissements tels que le CSS inutilisé, les conseils d'accessibilité, et
les erreurs de compilation JavaScript/TypeScript.

Il exécute `svelte-check` en interne, et uniquement s'il est installé dans votre projet (les
installations globales sont ignorées) :

```sh
npm i -D svelte-check
npx sv check
```

## Options

Toutes les [options de `svelte-check`](https://npmx.dev/package/svelte-check) sont relayées, plus :

### `-C`, `--cwd <path>`

Le chemin vers la racine de votre projet. Vaut par défaut le chemin dossier actuel.
