## Comment me servir du CLI `sv` ?

Exécuter `sv` se fait de manière légèrement différent pour chaque gestionnaire de paquets. Voici une
liste des commandes les plus communes :

- **npm** : `npx sv create`
- **pnpm** : `pnpx sv create` ou `pnpm dlx sv create`
- **Bun** : `bunx sv create`
- **Deno** : `deno run npm:sv create`
- **Yarn** : `yarn dlx sv create`

## `npx sv` ne fonctionne pas

Certains gestionnaires de paquets préfèrent exécuter des outils installés localement plutôt que de
télécharger et d'exécuter des paquets depuis un registre. Ce problème se produit le plus souvent
avec `npm` et `yarn`. Cela entraîne généralement un message d'erreur ou donne l'impression que la
commande que vous essayiez d'exécuter n'a rien fait du tout.

Voici une liste de problèmes déjà identifiés par le passé avec leur solution potentielle :

- [`sv` dans windows powershell entre en conflit avec `Set-Variable`](https://github.com/sveltejs/cli/issues/317)
