La manière la plus simple de créer une application SvelteKit est de lancer `npx sv create` :

```bash
npx sv create my-app
cd my-app
npm install
npm run dev
```

La première commande va préparer tout le nécessaire pour un nouveau projet dans le dossier `my-app`
en vous demandant si vous souhaitez certains outillages de base comme TypeScript. Voir le chapitre
sur les [intégrations](./integrations) pour plus d'infos sur les options d'outillage. Les commandes
suivantes vont ensuite installer les dépendances et lancer un serveur sur
[localhost:5173](http://localhost:5173).

Il y a deux principes de base :

- Chaque page de votre application est un composant [Svelte](../svelte)
- Vous créez des pages en ajoutant des fichiers dans le dossier `src/routes` de votre projet.
Celles-ci seront rendues côté serveur afin que la première visite d'une personne sur votre
application soit la plus rapide possible, puis l'application côté prend le relais

Essayez de modifier les fichiers pour avoir un aperçu de comment les choses fonctionnent.
