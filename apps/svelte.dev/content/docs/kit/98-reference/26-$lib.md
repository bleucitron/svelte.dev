Lorsque vous démarrez un nouveau projet SvelteKit avec le [CLI `sv`](/docs/cli/overview), un alias
d'import `#lib` est automatiquement créé pour votre dossier `src/lib/`, en ajoutant la configuration
suivante à votre fichier `package.json` :
automatiquement un alia

```json
{
	"imports": {
		"#lib": "./src/lib/index.js",
		"#lib/*": "./src/lib/*"
	}
}
```

Le préfixe `#` utilise une fonctionnalité intégrée à Node, les [imports de
sous-chemin](https://nodejs.org/api/packages.html#subpath-imports), qui réservent `#` pour les
alias internes des paquets. Vite et TypeScript résolvent cet alias nativement.

> [!LEGACY]
> Précédemment, cet alias était `$lib` et était automatiquement configuré par SvelteKit. L'alias est
> désormais `#lib` et doit être déclaré dans votre fichier `package.json` dans le champ `imports`.
> `import { foo } from '$lib/foo.js'` devient alors `import { foo } from '#lib/foo.js'`.

