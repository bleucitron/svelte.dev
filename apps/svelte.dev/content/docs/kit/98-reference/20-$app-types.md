Ce module contient les types générés pour les routes de votre application.

<blockquote class="since note">
	<p>Disponible depuis la version 2.26</p>
</blockquote>

```js
// @noErrors
import type { RouteId, RouteParams, LayoutParams } from '$app/types';
```

## Asset

Une union de tous les chemins de fichiers des assets contenus dans votre dossier `static`.

<div class="ts-block">

```dts
type Asset = '/favicon.png' | '/robots.txt';
```

</div>

## RouteId

Une union de tous les ID de route de votre application. Utilisée pour `page.route.id` et
`event.route.id`.

<div class="ts-block">

```dts
type RouteId = '/' | '/my-route' | '/my-other-route/[param]';
```

</div>

## Pathname

Une union de tous les chemins valides de votre application.

<div class="ts-block">

```dts
type Pathname = '/' | '/my-route' | `/my-other-route/${string}` & {};
```

</div>

## ResolvedPathname

Similaire à `Pathname`, mais possiblement préfixé avec un [chemin de
base](https://svelte.dev/docs/kit/configuration#paths). Utilisé pour `page.url.pathname`.

<div class="ts-block">

```dts
type ResolvedPathname = `${'' | `/${string}`}/` | `${'' | `/${string}`}/my-route` | `${'' | `/${string}`}/my-other-route/${string}` | {};
```

</div>

## RouteParams

Un utilitaire pour récupérer les paramètres associés avec une route donnée.

```ts
// @errors: 2552
type BlogParams = RouteParams<'/blog/[slug]'>; // { slug: string }
```

<div class="ts-block">

```dts
type RouteParams<T extends RouteId> = { /* generated */ } | Record<string, never>;
```

</div>

## LayoutParams

Un utilitaire pour récupérer les paramètres associés avec un layout donné, similaire à `RouteParams`
mais inclut également des paramètres optionnels pour toute route enfant.

<div class="ts-block">

```dts
type RouteParams<T extends RouteId> = { /* generated */ } | Record<string, never>;
```

</div>
