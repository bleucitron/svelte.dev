SvelteKit rend disponibles trois objets d'état en lecture seule via le module `$app/state`, —
`page`, `navigating` et `updated`.


```js
// @noErrors
import { navigating, page, updated } from '$app/state';
```

## navigating

Un objet en lecture seule représentant une navigation en cours, avec des propriétés `from`, `to`,
`type` et (si `type === 'popstate'`) `delta`.
Les valeurs de ces propriétés sont `null` lorsqu'aucune navigation n'est en cours, ou lors du rendu
côté serveur.

<div class="ts-block">

```dts
const navigating:
	| Navigation
	| {
			from: null;
			to: null;
			type: null;
			willUnload: null;
			delta: null;
			complete: null;
	  };
```

</div>



## page

Un objet réactif en lecture seule avec des informations concernant la page courante, servant
plusieurs cas d'usage :
- récupérer les `data` combinées de toutes les pages/layouts de votre arbre de composants (voir
également la section [charger des données](/docs/kit/load))
- récupérer la valeur courante de la propriété `form` n'importe où dans votre arbre de composant
(voir également la section [actions de formulaire](/docs/kit/form-actions))
- récupérer l'état de la page défini via `goto` (voir également les sections
[goto](/docs/kit/$app-navigation#goto), et [shallow routing](/docs/kit/shallow-routing))
- récupérer les métadonnées comme l'URL courante, la route courante et ses paramètres, et si oui ou
non une erreur s'est produite

```svelte
<!--- file: +layout.svelte --->
<script>
	import { page } from '$app/state';
</script>

<p>Actuellement sur la page {page.url.pathname}</p>

{#if page.error}
	<span class="red">Problème détecté</span>
{:else}
	<span class="small">Tous les systèmes sont opérationnels</span>
{/if}
```

Les changements sur l'objet `page` sont uniquement accessibles avec les runes. (La syntaxe ancienne
de réactivité ne va refléter aucun changement)

```svelte
<!--- file: +page.svelte --->
<script>
	import { page } from '$app/state';
	const id = $derived(page.params.id); // Ceci va correctement fourni l'id à jour sur cette page
	$: badId = page.params.id; // Ne pas utiliser ; ne va jamais être mis à jour après le chargement initial
</script>
```

Sur le serveur, les valeurs peuvent uniquement être lues lors du rendu (autrement dit, _pas_ dans
les fonctions `load`, par exemple). Dans le navigateur, les valeurs peuvent être lues à n'importe
quel moment.

<div class="ts-block">

```dts
const page: Page;
```

</div>



## updated

Une valeur réactive en lecture seule qui vaut initialement `false`.

SvelteKit vérifie s'il existe une nouvelle version de l'application lors des réponses de données, de
fonctions distantes, et d'actions de formulaire (via le header `x-sveltekit-version`), lorsque
l'onglet récupère le focus ou devient visible, et avec un intervalle de polling
([`version.pollInterval`](/docs/kit/configuration#version)). `updated.current` est défini à `true`
lorsqu'une nouvelle version est détectée. `updated.check()` va forcer une vérification immédiate,
indépendamment du polling.

<div class="ts-block">

```dts
const updated: {
	get current(): boolean;
	check(): Promise<boolean>;
};
```

</div>
