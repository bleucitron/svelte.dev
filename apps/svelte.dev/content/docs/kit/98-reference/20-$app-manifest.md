## routes

Un tableau d'objets représentant les routes de votre application. Seules les routes que le router
peut faire correspondre sont incluses — les dossiers qui ne comportent qu'un `+layout` ne sont pas
des routes en eux-mêmes.

Chaque objet a un `id`, plus des booléens `page` et `endpoint` décrivant si oui ou non la route a
un fichier `+page` et/ou un fichier `+server`. Les deux valent `true` pour une route qui possèdent
les deux, afin de pouvoir filtrer leurs fonctionnalités indépendamment :

```js
// @errors: 7031
import { routes } from '$app/manifest';

const pages = routes.filter((route) => route.page);
const endpoints = routes.filter((route) => route.endpoint);
```

```dts
const routes: ManifestRoute[];
```

## ManifestRoute

Une route de votre application, avec ses fonctionnalités. `page` indique la présence d'un fichier
`+page` tandis que `endpoint` indique la présence d'un fichier `+server`. Les deux valent `true`
lorsque les deux fichiers existent :

<div class="ts-block">

```dts
type ManifestRoute =
	| {
			id: Exclude<
				import('$app/types').PageRouteId,
				import('$app/types').EndpointRouteId
			>;
			page: true;
			endpoint: false;
	  }
	| {
			id: Exclude<
				import('$app/types').EndpointRouteId,
				import('$app/types').PageRouteId
			>;
			page: false;
			endpoint: true;
	  }
	| {
			id: Extract<
				import('$app/types').PageRouteId,
				import('$app/types').EndpointRouteId
			>;
			page: true;
			endpoint: true;
	  };
```
