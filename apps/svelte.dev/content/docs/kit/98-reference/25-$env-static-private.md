title: $env/static/private

Ce module permet d'accéder aux variables d'environnement qui sont injectés de manière _statique_
dans votre bundle lors de la compilation, et qui sont limitées à un accès _privé_.

|         | Runtime                                                                    | Build time                                                               |
| ------- | -------------------------------------------------------------------------- | ------------------------------------------------------------------------ |
| Private | [`$env/dynamic/private`](/docs/kit/$env-dynamic-private) | [`$env/static/private`](/docs/kit/$env-static-private) |
| Public  | [`$env/dynamic/public`](/docs/kit/$env-dynamic-public)   | [`$env/static/public`](/docs/kit/$env-static-public)   |

Les variables d'environnement statiques sont [chargées par
Vite](https://vitejs.dev/guide/env-and-mode.html#env-files) depuis les fichiers `.env` et
`process.env` lors de la compilation puis injectées dans votre bundle toujours lors de la
compilation, permettant des optimisations comme l'élimination de code mort.

**Accès _privé_ :**

- Ce module ne peut pas être importé dans du client client
- Ce module inclut des variables dont le nom ne commence _pas_ par
[`config.kit.env.publicPrefix`](/docs/kit/configuration#env), mais commence par
[`config.kit.env.privatePrefix`](/docs/kit/configuration#env) (si configuré)

Par exemple, étant donné l'environnement de compilation suivant :

```env
ENVIRONMENT=production
PUBLIC_BASE_URL=http://site.com
```

Avec les valeurs par défaut de `publicPrefix` et `privatePrefix` :

```ts
import { ENVIRONMENT, PUBLIC_BASE_URL } from '$env/static/private';

console.log(ENVIRONMENT); // => "production"
console.log(PUBLIC_BASE_URL); // => jette une erreur lors de la compilation
```

Les valeurs ci-dessus seront les mêmes _même si_ des valeurs différentes pour `ENVIRONMENT` ou
`PUBLIC_BASE_URL` sont définies lors de l'exécution, puisqu'elles sont remplacées de manière
statique dans votre code avec leurs valeurs de compilation.
