Ce module contient la configuration TypeScript taillée pour votre service worker :

```json
/// file: src/service-worker/tsconfig.json
{
	"extends": "$app/tsconfig/service-worker"
}
```

Vous pouvez étendre cette configuration avec vos propres `compilerOptions`, en appliquant les mêmes
contraintes que celles présentées dans [`$app/tsconfig`]($app-tsconfig).
