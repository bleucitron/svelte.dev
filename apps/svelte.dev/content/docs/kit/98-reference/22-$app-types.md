Ce module contient des types générés pour les routes de votre application.

<blockquote class="since note">
	<p>Available since 2.26</p>
</blockquote>

```js
// @noErrors
import type { RouteId, PageRouteId, EndpointRouteId, RouteParams, LayoutParams } from '$app/types';
```

## AssetPath

Une union de tous les chemins d'assets contenus dans votre dossier `static`, relativement au chemin
`base`.

<div class="ts-block">

```dts
type AssetPath = 'favicon.png' | 'robots.txt' | (string & {});
```

</div>

## RouteId

Une union de tous les IDs de route de votre application — l'union de `PageRouteId` et
`EndpointRouteId`. Utilisée pour `page.route.id` et `event.route.id`.

<div class="ts-block">

```dts
type RouteId = '/' | '/my-route' | '/my-other-route/[param]' | '/my-endpoint';
```

</div>

## PageRouteId

Une union des IDs de route de votre application ayant un fichier `+page`.

Un ID de route peut être à la fois dans `PageRouteId` et dans `EndpointRouteId`, si le dossier
contient à la fois un fichier `+page` et un fichier `+server`. Dans l'exemple ci-dessous,
`/my-route` a les deux.

<div class="ts-block">

```dts
type PageRouteId = '/' | '/my-route' | '/my-other-route/[param]';
```

</div>

## EndpointRouteId

Une union des IDs de route de votre application ayant un fichier `+server`.

Un ID de route peut être à la fois dans `PageRouteId` et dans `EndpointRouteId`, si le dossier
contient à la fois un fichier `+page` et un fichier `+server`. Dans l'exemple ci-dessous,
`/my-route` a les deux.

<div class="ts-block">

```dts
type EndpointRouteId = '/my-route' | '/my-endpoint';
```

</div>

## Path

Une union de tous les chemins valides de votre application, relativement au chemin `base`.

<div class="ts-block">

```dts
type Path = '' | 'my-route' | `my-other-route/${string}` & {};
```

</div>

## ResolvedPathname

Similaire à `Path`, mais préfixé avec un [chemin de base](@sveltejs-kit-vite#paths). Utilisé pour
`page.url.pathname`.

<div class="ts-block">

```dts
type ResolvedPathname = `${'' | `/${string}`}/` | `${'' | `/${string}`}/my-route` | `${'' | `/${string}`}/my-other-route/${string}` | {};
```

</div>

## RouteParams

Un utilitaire pour obtenir les paramètres associés à une route donnée.

```ts
// @errors: 2552
type BlogParams = RouteParams<'/blog/[slug]'>; // { slug: string }
```

<div class="ts-block">

```dts
type RouteParams<T extends RouteId> = { /* generated */ } | Record<string, never>;
```

</div>

## LayoutParams

Un utilitaire pour obtenir les paramètres associés à un layout donné, qui est similaire à
`RouteParams` mais inclut également des paramètres optionnels pour toute route enfant. Il accepte
l'ID de route de tout dossier contenant un layout, incluant les dossiers ne contenant qu'un layout
qui ne font pas partie de `RouteId`.

<div class="ts-block">

```dts
type LayoutParams<T extends '/' | '/my-layout' | '/my-other-layout'> = { /* generated */ };
```

</div>
