title: $env/static/public

Similaire à [`$env/static/private`](/docs/kit/$env-static-private), sauf qu'il n'inclut que les
variables d'environnement dont le nom commence par
[`config.kit.env.publicPrefix`](/docs/kit/configuration#env) (qui vaut par défaut `PUBLIC_`), et qui
peuvent donc être exposées sans risques au code client.

Les valeurs sont remplacées de manière statique au moment de la compilation.

```ts
import { PUBLIC_BASE_URL } from '$env/static/public';
```
