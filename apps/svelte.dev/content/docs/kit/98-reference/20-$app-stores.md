Ce module contient des équivalents aux exports du module [`$app/state`]($app-state), mais basés sur
des stores. Si vous utilisez SvelteKit 2.12 ou plus récent, utilisez plutôt `$app/state`.


```js
// @noErrors
import { getStores, navigating, page, updated } from '$app/stores';
```

## navigating

<blockquote class="tag deprecated note">

Utilisez plutôt `navigating` importé depuis `$app/state` (nécessite Svelte 5, voir la [documentation
pour plus
d'informations](/docs/kit/migrating-to-sveltekit-2#SvelteKit-2.12:-$app-stores-deprecated))

</blockquote>

Un store de lecture.
Lorsque la navigation commence, sa valeur est un objet `Navigation` avec des propriétés `from`,
`to`, `type` et (si `type === 'popstate'`) `delta`.
Lorsqu'une navigation se termine, sa valeur revient à `null`.

Sur le serveur, il est uniquement possible de s'abonner à ce store lors de l'initialisation d'un
composant. Dans le navigateur, vous pouvez vous y abonner à tout moment.

<div class="ts-block">

```dts
const navigating: import('svelte/store').Readable<
	import('@sveltejs/kit').Navigation | null
>;
```

</div>



## page

## updated

<blockquote class="tag deprecated note">

Utilisez plutôt `updated` importé depuis `$app/state` (nécessite Svelte 5, voir la [documentation pour
plus d'informations](/docs/kit/migrating-to-sveltekit-2#SvelteKit-2.12:-$app-stores-deprecated))

</blockquote>

Un store de lecture dont la valeur initiale est `false`. Si
[`version.pollInterval`](/docs/kit/configuration#version) est une valeur différente de zéro,
SvelteKit va régulièrement vérifier (en faisant du _polling_) s'il existe de nouvelles versions de
l'application et mettre à jour `current` à `true` lors qu'une nouvelle version existe.
`updated.check()` permet de forcer une vérification immédiate, indépendamment du polling.

Sur le serveur, il est uniquement possible de s'abonner à ce store lors de l'initialisation d'un
composant. Dans le navigateur, vous pouvez vous y abonner à tout moment.

<div class="ts-block">

```dts
const updated: import('svelte/store').Readable<boolean> & {
	check(): Promise<boolean>;
};
```

</div>
