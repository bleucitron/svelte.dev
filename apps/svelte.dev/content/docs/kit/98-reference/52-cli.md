Les projets SvelteKit utilisent [Vite](https://vitejs.dev), ce qui veut dire que vous utiliserez
principalement son CLI (bien que via des scripts `npm run dev/build/preview`) :

- `vite dev` — lancer un serveur de développement
- `vite build` — compiler une version de production de votre application
- `vite preview` — lancer la version de production localement

Toutefois, SvelteKit a son propre CLI pour initialiser votre projet :

## svelte-kit sync

`svelte-kit sync` crée le fichier `tsconfig.json` et tous les types générés (que vous pouvez
importer en tant que `./$types` dans vos fichiers de routing) de votre projet. Lorsque vous créez un
nouveau projet, il est listé en tant que script `prepare` et sera exécuté automatiquement en tant
qu'étape du cycle de vie npm, vous ne devriez donc pas avoir à exécuter cette commande.
