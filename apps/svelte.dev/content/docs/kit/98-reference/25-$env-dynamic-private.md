Ce module permet d'accéder aux variables d'environnement définies _dynamiquement_ lors de
l'exécution et qui sont restreintes à un accès _privé_.

|         | Runtime                                                                    | Build time                                                               |
| ------- | -------------------------------------------------------------------------- | ------------------------------------------------------------------------ |
| Private | [`$env/dynamic/private`](/docs/kit/$env-dynamic-private) | [`$env/static/private`](/docs/kit/$env-static-private) |
| Public  | [`$env/dynamic/public`](/docs/kit/$env-dynamic-public)   | [`$env/static/public`](/docs/kit/$env-static-public)   |

Les variables d'environnement dynamiques sont définies par votre plateforme d'exécution. Par
exemple, si vous utilisez
[`adapter-node`](https://github.com/sveltejs/kit/tree/main/packages/adapter-node) (ou si vous
utilisez [`vite preview`](/docs/kit/cli)), ceci est équivalent à `process.env`.

**Accès _privé_ :**

- Ce module ne peut pas être importé dans du client client
- Ce module inclut des variables dont le nom ne commence _pas_ par
[`config.kit.env.publicPrefix`](/docs/kit/configuration#env), mais commence par
[`config.kit.env.privatePrefix`](/docs/kit/configuration#env) (si configuré)

> [!NOTE] En mode `dev`, `$env/dynamic` contient des variables d'environnement de `.env`. En mode
> `prod`, ce comportement dépend de votre adaptateur.

> [!NOTE] Pour avoir accès à un typage correct, les variables d'environnement référencées dans votre
> code doivent être déclarées (par exemple dans un fichier `.env`), même si elles n'ont pas de
> valeur avant le déploiement de l'application :
>
> ```env
> MY_FEATURE_FLAG=
> ```
>
> Vous pouvez écraser les valeurs de `.env` depuis la ligne de commande de cette manière :
>
> ```sh
> MY_FEATURE_FLAG="enabled" npm run dev
> ```

Par exemple, étant donné l'environnement d'exécution suivant :

```env
ENVIRONMENT=production
PUBLIC_BASE_URL=http://site.com
```

Avec les valeurs par défaut de `publicPrefix` et `privatePrefix` :

```ts
import { env } from '$env/dynamic/private';

console.log(env.ENVIRONMENT); // => "production"
console.log(env.PUBLIC_BASE_URL); // => undefined
```
