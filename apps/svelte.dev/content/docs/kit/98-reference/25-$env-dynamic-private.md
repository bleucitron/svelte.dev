title: $env/dynamic/private
---

Ce module fournit un accès aux variables d'environnement d'exécution, telles que définies par la
plateforme sur laquelle votre application est exécutée. Par exemple, si vous utilisez
[`adapter-node`](https://github.com/sveltejs/kit/tree/main/packages/adapter-node) (ou si vous
exécutez [`vite preview`](/docs/kit/cli)), ceci est équivalent à `process.env`. Ce module n'inclut
que les variables dont le nom ne _commence pas_ par
[`config.kit.env.publicPrefix`](/docs/kit/configuration#env) et _commence_ par
[`config.kit.env.privatePrefix`](/docs/kit/configuration#env) (si configuré).

Ce module ne peut pas être importé dans du code client.

Les variables d'environnement dynamiques ne peuvent pas être utilisées lors du pré-rendu.

```ts
import { env } from '$env/dynamic/private';
console.log(env.DEPLOYMENT_SPECIFIC_VARIABLE);
```

> En mode `dev`, `$env/dynamic` inclut toujours les variables d'environnement du fichier `.env`. En
> mode `prod`, ce comportement dépend de votre adaptateur.
