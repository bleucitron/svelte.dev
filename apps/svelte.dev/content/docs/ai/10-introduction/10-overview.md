Les pages suivantes vous aideront à mettre en place et à utiliser les outils d'IA officiellement
maintenus par l'équipe Svelte.

Il existe quatre outils, conçus pour aider votre agent à écrire du code Svelte correct et robuste.
Ils ont été conçus pour fonctionner ensemble, mais peuvent être utilisés individuellement :

- [Instructions](instructions): un petit prompt qui sera toujours injecté dans votre session pour
rendre votre agent mieux conscient des outils disponibles
- [Serveur MCP](mcp): avec des outils, des prompts et des ressources pour donner à votre agent plus
de contexte, en utilisant directement la documentation Svelte officielle et en utilisant de
l'analyse statique pour corriger les erreurs classiques de l'IA générative.
- [Skills](skills): des descriptions chargées en parallèle pour enseigner à votre agent les bonnes
pratiques, ainsi que comment utiliser le [CLI du `@sveltejs/mcp`](cli)
- [Subagents](subagent): des agents dédiés pouvant être invoqués en parallèle pour exécuter des
opérations atomiques dans une fenêtre de contexte distincte
