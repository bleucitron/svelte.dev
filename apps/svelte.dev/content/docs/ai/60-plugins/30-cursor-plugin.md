Cursor un [système de plugins](https://cursor.com/docs/plugins) qui contient des règles, des skills,
des agents, des commandes, des serveurs MCP, et des hooks.

Le plugin Svelte vous fournit le serveur MCP Svelte local (stdio), les [skills](skills) Cursor, une
règle toujours active disant à votre modèle comment utiliser les outils du serveur MCP de Svelte
correctement, et le sous-agent `svelte-file-editor` pour travailler avec les fichiers `.svelte` et
les modules `.svelte.ts`/`.svelte.js`. La source est disponible dans le projet
[`sveltejs/ai-tools`](https://github.com/sveltejs/ai-tools/tree/main/plugins/cursor/svelte).

## Installation

Installez le plugin depuis la [Marketplace de Cursor](https://cursor.com/marketplace/svelte) avec la
commande suivante :

```
/add-plugin svelte
```

Les plugins peuvent être installés soit pour le projet courant ou au niveau utilisateur.

Une fois installé, Cursor va automatiquement trouver les composants du plugin :

- le serveur MCP de Svelte est ajouté depuis le `.mcp.json` du plugin
- les règles et les skills apparaissent dans l'interface de règles de Cursor
- l'agent `svelte-file-editor` devient disponible dans le chat

> [!NOTE] Le CLI de Cursor ne supporte pas encore les plugins. Le support des plugins dans les
> [Cloud Agents](https://cursor.com/docs/cloud-agent) est limité aux serveurs MCP.
