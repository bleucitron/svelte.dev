Les outils suivants sont fournis par le serveur MCP au modèle que vous utilisez, qui peut décider
d'en utiliser un ou plusieurs lors d'une session :

## list-sections

Fournit une liste de toutes les sections de la documentation disponibles.

## get-documentation

Permet au modèle de récupérer la documentation complète (et à jour) pour les sections demandées
directement depuis [svelte.dev/docs](/docs).

## svelte-autofixer

Utilise l'analyse statique pour fournir des suggestions pour le code que votre LLM génère. Il peut
être invoqué par votre modèle dans une boucle d'agent jusqu'à ce que tous les problèmes et
suggestions soient résolues.

## playground-link

Génère un lien éphémère de bac à sable avec le code généré. C'est utile lorsque le code généré n'est
pas écrit dans un fichier de votre projet, et que vous souhaitez rapidement tester la solution
générée. Le code n'est stocké nulle part à l'exception de l'URL elle-même (qui sera souvent, en
conséquence, plutôt longue).
