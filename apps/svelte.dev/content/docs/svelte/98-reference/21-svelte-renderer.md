## createRenderer

Crée un custom renderer.

Les types des noeuds du renderer sont inférés des types de retour de `createFragment`,
`createElement`, `createTextNode` et `createComment`, tant que ces méthodes viennent avant les
autres. Vous pouvez également les passer en tant qu'argument de type :

```ts
const renderer = createRenderer<{ fragment: MyFragment; element: MyElement; text: MyText; comment: MyComment }>({
	// ...
});
```

Seul le premier paramètre de type est prévu pour être fourni ; les autres existent afin que les
types de noeud puissent être inférés à partir des méthodes (TypeScript ne peut pas inférer l'objet
lui-même à partir de ces méthodes).

<div class="ts-block">

```dts
function createRenderer<
	N extends RendererNodes = RendererNodes,
	TFragment extends object = N['fragment'],
	TElement extends object = N['element'],
	TText extends object = N['text'],
	TComment extends object = N['comment']
>(
	renderer: Renderer<{
		fragment: TFragment;
		element: TElement;
		text: TText;
		comment: TComment;
	}>
): Renderer<{
	fragment: TFragment;
	element: TElement;
	text: TText;
	comment: TComment;
}>;
```

## Renderer

Un custom renderer. `N` décrit les types des noeuds du renderer, par exemple :

```ts
const renderer: Renderer<{ fragment: MyFragment; element: MyElement; text: MyText; comment: MyComment }> = ...
```

<div class="ts-block">

```dts
type Renderer<N extends RendererNodes = RendererNodes> = {
	/** Crée un fragment, un conteneur pour plusieurs noeuds. Insérer un fragment devrait insérer
tout ses enfants. */
	createFragment(): N['fragment'];

	/** Crée un élément avec le nom fourni */
	createElement(name: string): N['element'];

	/** Crée un noeud texte avec le texte fourni. */
	createText(data: string): N['text'];

	/**
	 * Crée un noeud de commentaire avec la donnée fournie.
	 * Cette méthode est souvent utilisée comme un ancre pour insérer des éléments ; ce noeud n'a
nécessairement besoin d'être rendu.
	 */
	createComment(data: string): N['comment'];

	/** Renvoie le type du noeud : `'fragment'`, `'element'`, `'text'` ou `'comment'`. */
	getNodeType(node: N[NodeType]): NodeType;

	/** Renvoie le texte d'un noeud texte, ou les données d'un commentaire. */
	getText(node: N['text'] | N['comment']): string | null;

	/** Renvoie la valeur de l'attribut ayant le nom fourni sur l'élément, ou `null` sinon. */
	getAttribute(
		element: N['element'],
		name: string
	): string | null;

	/** Définit l'attribut avec le nom et la valeur fournies sur l'élément. */
	setAttribute(
		element: N['element'],
		key: string,
		value: any
	): void;

	/** Supprime de l'élément l'attribut ayant le nom fourni. */
	removeAttribute(
		element: N['element'],
		name: string
	): void;

	/** Renvoie `true` si l'élément a un attribut ayant le nom fourni. */
	hasAttribute(
		element: N['element'],
		name: string
	): boolean;

	/** Définit le texte d'un noeud texte. */
	setText(node: N['text'], text: string): void;

	/** Renvoie le premier enfant d'un élément ou d'un fragment, ou `null` s'il n'a pas d'enfant. */
	getFirstChild(
		element: N['element'] | N['fragment']
	): N[NodeType] | null;

	/** Renvoie le dernier enfant d'un élément ou d'un fragment, ou `null` s'il n'a pas d'enfant. */
	getLastChild(
		element: N['element'] | N['fragment']
	): N[NodeType] | null;

	/** Renvoie l'élément suivant du noeud, ou `null` s'il n'y en a pas d'autre. */
	getNextSibling(
		node: N['element'] | N['text'] | N['comment']
	): N[NodeType] | null;

	/**
	 * Insère le noeud dans le parent avant l'ancre, ou à la fin si l'ancre est `null`.
	 * Insérer un fragment devrait insérer ses enfants (et laisser le fragment vide).
	 */
	insert(
		parent: N['element'] | N['fragment'],
		node: N[NodeType],
		anchor: N['element'] | N['text'] | N['comment'] | null
	): void;

	/** Supprime le noeud de l'arbre. */
	remove(
		node: N['element'] | N['text'] | N['comment']
	): void;

	/** Renvoie le parent du noeud, ou `null` s'il n'a pas de parent. */
	getParent(
		node: N['element'] | N['text'] | N['comment']
	): N[NodeType] | null;

	/** Ajoute un gestionnaire d'évènement avec le type et la fonction fournies au noeud cible. */
	addEventListener(
		target: N['element'],
		type: string,
		handler: any,
		options?: any
	): void;

	/** Supprime un gestionnaire d'évènement ayant le type et la fonction fournies du noeud cible.
*/
	removeEventListener(
		target: N['element'],
		type: string,
		handler: any,
		options?: any
	): void;

	/**
	 * Exécutée lorsqu'un composant (ou un snippet) qui utilise ce renderer est rendu au sein d'un
	 * contenu appartenant à un renderer différent (`host` vaut `null` pour le DOM).
	 *
	 * Renvoie un `container` appartenant à ce renderer dans lequel le contenu sera rendu, et
	 * optionnellement un `node` appartenant au `host` qui représent le contenu dans l'arbre de
	 * l'hôte. Si aucun `node` n'est renvoyé, un noeud texte vide est utilisé.
	 *
	 * `parent` est le parent (appartenant au `host`) de la position à laquelle le rendu est
	 * effectué, ce qui rend possible de faire un rendu dans un élément que l'utilisateur ou
	 * utilisatrice a écrit, par exemple un `<canvas>`.
	 */
	embed?(context: {
		host: Renderer<any> | null;
		parent: unknown;
		anchor: unknown;
	}): RendererConnection<
		unknown,
		N['element'] | N['fragment']
	>;

	/**
	 * Exécutée lorsqu'un composant (ou un snippet) qui utilise un renderer différent (`guest` vaut
	 * `null` pour le DOM) est rendu au sein de contenu appartenant à ce renderer, et que le renderer
	 * `guest` ne définit pas de méthode `embed`.
	 *
	 * Renvoie un `container` appartenant au renderer `guest` dans lequel le contenu sera rendu, et
	 * optionnellement un `node` appartenant à ce renderer représentant le contenu dans cet arbre.
	 */
	host?(context: {
		guest: Renderer<any> | null;
		parent: N['element'] | N['fragment'] | null;
		anchor: N['element'] | N['text'] | N['comment'];
	}): RendererConnection<
		N['element'] | N['text'] | N['comment'],
		unknown
	>;
};
```

</div>

## RendererConnection

Décrit comment le contenu appartenant à un renderer est attaché à du contenu appartenant à un autre
renderer

<div class="ts-block">

```dts
type RendererConnection<THostNode, TContainer> = {
	/** Un noeud appartenant au renderer `host` représentant le contenu dans l'arbre `host` */
	node?: THostNode;
	/** Un noeud appartenant au renderer `guest` dans lequel le contenu est rendu */
	container: TContainer;
	/** Exécuté après la suppression du contenu */
	destroy?(): void;
};
```
